> Generate fake corrupted files with valid headers but random, unreadable content.

![Demo Preview](https://via.placeholder.com/800x400?text=Fake+Damaged+File+Generator+Preview)

## 🌟 Features

- **Multiple File Types** - Support for video (MP4, AVI, MKV, MOV), Office documents (DOCX, XLSX, PPTX), images (JPG, PNG, GIF), and more
- **Customizable Size** - Generate files from KBs up to 500MB with preset or custom sizes
- **Randomized Names** - Auto-generate realistic filenames with one click
- **Bilingual Interface** - Full Persian (RTL) and English support
- **No Server Required** - 100% client-side, runs entirely in your browser
- **Mobile Responsive** - Works on desktop, tablet, and mobile devices

## 🎯 Use Cases

- ✅ **Testing download handlers** - Verify how your app handles corrupted downloads
- ✅ **Error recovery testing** - Test file repair and error detection systems
- ✅ **Bandwidth simulation** - Generate files of specific sizes for network testing
- ✅ **File validation systems** - Test your file upload validation logic
- ✅ **Educational purposes** - Learn about file headers and binary data
